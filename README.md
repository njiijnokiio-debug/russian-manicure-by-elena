# Russian Manicure by Elena — сайт

Статический сайт (HTML + CSS + JS, без сборщиков). Открывается на любом хостинге:
загрузите содержимое папки в корень домена (Netlify, Vercel, GitHub Pages, любой
простой хостинг с FTP).

- `index.html` — вся страница (одностраничный сайт, все разделы на одном экране)
- `assets/css/styles.css` — стили
- `assets/js/main.js` — переводы EN/RU, меню, галерея, анимации
- `assets/img/` — изображения-заглушки (SVG) и `og-image.png`

Локальный просмотр: любым локальным сервером, например
`npx serve .` или `python -m http.server` (просто открыть `index.html` двойным
кликом тоже можно, но карта Google и шрифты лучше проверять через сервер).

* **Услуги и цены** — уточняют в Instagram или WhatsApp. Кнопки WhatsApp
  стоят в разделе «Services», в финальном CTA, в мобильном меню и в подвале

## 2. Фотографии (сейчас — стилизованные заглушки)

Замените файлы в `assets/img/`, сохранив имена, — вёрстка не сломается:

| Файл | Где на сайте |
|---|---|
| `hero.svg` | Большое фото в шапке (герой). Рекомендуется JPG/WebP 1920×1200 |
| `about-portrait.svg` | Портрет в разделе «About» (4:5, например 1000×1250) |
| `service-01.svg` … `service-05.svg` | Карточки услуг (4:5) |
| `portfolio-01.svg` … `portfolio-09.svg` | Галерея (разные форматы, можно любые) |
| `og-image.png` | Превью при отправке ссылок в соцсети (1200×630) |
| `favicon.svg` | Иконка во вкладке |

В `index.html` у каждого `<img>` можно поправить `alt` (текст для поисковиков
и экранного ридера) под реальное фото.

Портфолио лучше всего наполнять настоящими работами из Instagram — тогда
раздел «Follow on Instagram» под заголовком станет логичным продолжением.

## 3. Услуги (карточки 02–05 — заглушки)

Карточка 01 — «Russian Manicure» (подтверждённая услуга). Карточки 02–05
помечены бейджем **«To be replaced» / «Заменить»** и текстом-заглушкой.

В `index.html` у каждой такой карточки замените:

* `<h3 class="service-card__title" data-i18n="services.ph_name">` — название;
* `<p class="service-card__desc" data-i18n="services.ph_desc">` — описание;
* при необходимости уберите класс `service-card--ph` (убирает подчёркивание
  и бейдж `service-card__badge`).

Цену пока нигде не указываем: стоит строка «Contact for current pricing /
Цена по запросу». Как только появится прайс — добавьте цену в карточку и
поправьте переводы в `assets/js/main.js`.

## 4. Переводы EN / RU

* Английский — язык по умолчанию, русский — по переключателю **EN | RU**.
* Всё содержимое лежит в словаре `DICT` внутри `assets/js/main.js`
  (блоки `en:` и `ru:`). Ключи совпадают с атрибутами `data-i18n="..."`
  в HTML.
* **Если добавляете или меняете текст — меняйте в обоих блоках (en и ru).**
* Выбранный язык запоминается в браузере (`localStorage`), заголовок
  страницы и meta-описание тоже переключаются.

## 6. Домен (canonical, Open Graph)

В начале `index.html` замените `https://russianmanicurebyelena.com/` на
реальный адрес сайта во всех местах:

* `<link rel="canonical">`
* `og:url`, `og:image`
* `twitter:image`
* JSON-LD блок `"url"` и `"image"`

## 7. Публикация на GitHub Pages

Сайт уже опубликован как статический репозиторий (ветка `main`, папка корня).
После пула новых изменений Pages обновляется сам за 1–3 минуты.

Ручная проверка: в настройках репозитория → Pages → Source: `main` / `(root)`.
